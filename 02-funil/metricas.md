## AS TRÊS MÉTRICAS QUE IMPORTAM MAIS NESTE PROJETO

Recomendação, não consenso de mercado:

### 1. TAXA DE SALVAMENTO
É o indicador mais honesto de que o conteúdo atingiu. A pessoa salva o que a incomodou e que
ela quer reler. Curtida é cortesia; salvamento é impacto.

### 2. COMPARTILHAMENTO EM DM
Distingue "gostei" de "isso é sobre você" — a pessoa está usando o conteúdo para dizer algo a
outra pessoa. É o mecanismo de distribuição mais barato do funil e o mais alinhado com a tese
do livro (o padrão é herdado e reconhecido em terceiros antes de ser reconhecido em si).

### 3. CLIQUES NO LINK ÷ ALCANCE
Mede DESEJO isolado do alcance. Alcance alto com clique baixo significa que o conteúdo está
entretendo, não convertendo — o sintoma clássico de desconforto ausente.

## MÉTRICAS DE VAIDADE — NÃO OTIMIZAR PARA ESTAS

- Número bruto de seguidores
- Curtidas
- Visualizações sem retenção
- Comentários de uma palavra ("❤️", "top", "lindo")

O último merece atenção especial: **comentário elogioso raso é sinal de alerta**, não de sucesso.
Significa que a peça foi bonita e não desconfortável.

## COMO REGISTRAR APRENDIZADO

Toda hipótese testada vira uma linha permanente:

```markdown
| Data | Hipótese | Resultado | Conclusão | Status |
|---|---|---|---|---|
| | | | | CONFIRMADA / REFUTADA / INCONCLUSIVA |
```

INCONCLUSIVA é um resultado legítimo e deve ser registrado como tal. Forçar conclusão a partir
de dado insuficiente é como se constrói uma estratégia inteira sobre coincidência.
