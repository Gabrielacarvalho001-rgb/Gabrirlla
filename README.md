Não é arquivo de conteúdo pronto. É o **sistema que decide** o que vira conteúdo.

## TRÊS REGRAS DE OPERAÇÃO

1. **Nada aqui é dado até ser marcado como dado.** Toda afirmação é `DADO COMPROVADO`,
   `HIPÓTESE` ou `RECOMENDAÇÃO`. Confundir os três é como se constrói estratégia sobre ficção.

2. **`[LACUNA]` significa: não decida isso ainda.** Enquanto o marcador existir,
   qualquer decisão sobre aquele ponto é palpite com aparência de plano.

3. **Validação confortável custa mais caro que crítica desconfortável.**
   Ver `03-operacao/matriz-anti-cliche.md` — Regra de Ouro.
