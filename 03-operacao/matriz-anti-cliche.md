## ETAPA 1 — SEMÁFORO DE SATURAÇÃO

**Pergunta única:** *"Quantas outras autoras poderiam postar exatamente isso sem mudar uma palavra?"*

| | Critério | Ação |
|---|---|---|
| 🔴 **VERMELHO** | Motivacional, superficial, previsível. "5 passos para...", "acredite em você". | **Matar.** Não refatorar — reconstruir do zero com outra premissa. |
| 🟡 **AMARELO** | Ideia com substância, execução já vista no Instagram. | **Refatorar** até virar verde. Registrar o motivo da refatoração. |
| 🟢 **VERDE** | Tese contraintuitiva, específica, desconfortável, impossível de atribuir a outro criador. | **Produzir.** |

Ideia vermelha refatorada continua vermelha. O problema dela é a premissa, não a redação.

## ETAPA 2 — FRAMEWORK DE 12 DIMENSÕES

Para ideias que passaram do semáforo. Nota 0–10:

| Dimensão | O que avaliar | Nota |
|---|---|---|
| Força do conceito | Tem substância real? | |
| Originalidade | Poderia ter sido postada por qualquer autora? | |
| Identificação | O leitor se reconhece? | |
| Compartilhamento | Por que alguém enviaria isso a outra pessoa? | |
| Viralização | Tem tensão, polêmica inteligente, contraste? | |
| Comentários | Provoca reação ou é só "lindo"? | |
| Seguidores | Atrai o público certo? | |
| Conversão | Move em direção à compra? | |
| Coerência com o livro | Reflete a identidade da obra? | |
| Coerência com a autora | Reflete a personalidade de Gabriella? | |
| Força visual | Funciona como imagem ou vídeo? | |
| Serialização | Pode virar série ou campanha? | |

**Veredicto obrigatório:**

```
EU FARIA ✓ — [razão objetiva]
EU NÃO FARIA ✗ — [razão objetiva + alternativa concreta]
```

Veredicto sem alternativa não é crítica, é obstrução. Todo ✗ vem acompanhado de um caminho.

## ETAPA 3 — QUATRO PORTÕES FINAIS

Antes de produzir:

1. Tem **função de conteúdo** declarada? (ATRAIR / ENVOLVER / POSICIONAR / CONVERTER / RETER)
2. Rastreia até uma das **três frases-matriz**? (`00-fundacao/tese-central.md`)
3. Tem os **quatro elementos** da equação emocional — curiosidade, identificação, desconforto, desejo?
4. Sobreviveu ao **teste de propriedade**? (`00-fundacao/voz-e-linguagem.md`)

Quatro "sim" → produzir.

## PRINCÍPIO DE CRÍTICA — REGRA DE OURO

Este repositório e quem opera com ele **nunca concordam automaticamente**.

| Situação | Resposta |
|---|---|
| Ideia ruim | Dizer que é ruim e explicar por quê |
| Ideia clichê | Dizer que é clichê **e reescrever** |
| Ideia boa, melhorável | Melhorar e explicar a diferença |
| Ideia bonita, sem força comercial | Priorizar estratégia sobre estética |
| Ideia excelente | Potencializar sem fingir que é perfeita |

Validação confortável custa mais caro que crítica desconfortável. A primeira gasta meses;
a segunda gasta cinco minutos.
